# Tailwind Daily Tasks

A collection of daily frontend development tasks built using **HTML** and **Tailwind CSS**.

The purpose of this repository is to practice Tailwind CSS by creating different responsive websites and UI designs.

## Projects

| Day   | Project                | Description                                         |
| ----- | ---------------------- | --------------------------------------------------- |
| Day 1 | Application Form       | Responsive application form built with Tailwind CSS |
| Day 2 | Tailwind Task 2        | Responsive webpage using Tailwind CSS               |
| Day 3 | NAB Banking Website    | Banking website UI built with Tailwind CSS          |
| Day 4 | Incredible India       | Tourism website showcasing India                    |
| Day 5 | Covai Anganan Biriyani | Restaurant/food website                             |
| Day 6 | ShopEasy E-Commerce    | Responsive e-commerce website                       |
| Day 7 | Tailwind Task 7        | Tailwind CSS practice project                       |
| Final | Final Tailwind Task    | Final project demonstrating Tailwind CSS concepts   |

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/pravin-jasper/TAILWIND_DAILY_TASKS.git
```

### 2. Open the project

```bash
cd TAILWIND_DAILY_TASKS
```

### 3. Run the website

Open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.

## Navigation

The root `index.html` acts as the main dashboard and provides links to each daily Tailwind CSS project.

The projects use the Tailwind CSS CDN, making them easy to run without installing additional dependencies.

```html
<script src="https://cdn.tailwindcss.com"></script>
```
