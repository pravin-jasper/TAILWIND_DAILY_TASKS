# 🇮🇳 Incredible India
A responsive Incredible India tourism website built with HTML5 and Tailwind CSS.
 Features
Responsive navigation bar
Mobile-friendly menu
Full-screen tourism video hero section
Destination showcase
Attractions section
Travel diaries
Travel itinerary cards
Lesser-known Indian destinations
Indian crafts showcase
Festivals and events
Travel booking/search form
Responsive layouts
Tailwind CSS animations
 Technologies
HTML5
Tailwind CSS
HTML5 Video
Responsive Design
Tailwind CSS is loaded using the browser CDN:
```html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```
