#  Covai Anganan Biriyani

A responsive food website created for **Covai Anganan Biriyani**, showcasing traditional Coimbatore-style biriyani and other food items.

##  Project Overview

This website presents:

-  Chicken dishes
-  Biriyani
-  Chicken Delights
-  Parotta
-  Egg Specials
-  Chicken Noodles
-  Prawn dishes
-  About the restaurant
-  Contact information
-  Food delivery links

##  Technologies Used

- HTML5
- Tailwind CSS
- Google Fonts
- Responsive Design
