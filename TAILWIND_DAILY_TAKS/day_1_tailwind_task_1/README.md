# Application Form

A simple and responsive **Application Form** built using **HTML** and **Tailwind CSS**.

##  About the Project

This project contains a basic application form that allows users to enter their personal information and upload a file.

The form includes:

* First Name
* Last Name
* Phone Number
* Email ID
* File Upload
* Date
* Time
* Submit Button

##  Technologies Used

* HTML5
* Tailwind CSS
* JavaScript CDN for Tailwind CSS

##  Features

* Simple and clean user interface
* Responsive viewport configuration
* Tailwind CSS styling
* Text, number, email, date, and time input fields
* File upload option
* Styled submit button

##  Project Structure

```text
Application-Form/
│
├── index.html

```

##  How to Run


1. Open the project folder.

2. Open `index.html` in your web browser.

No additional installation is required because Tailwind CSS is loaded through the CDN.
