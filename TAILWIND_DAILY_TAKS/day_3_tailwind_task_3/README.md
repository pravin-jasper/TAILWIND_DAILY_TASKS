# NAB Banking Website

A responsive banking website UI inspired by the NAB banking website, built using **HTML5** and **Tailwind CSS**.

##  Project Overview

This project is a frontend implementation of a modern banking homepage. It includes:

* Responsive navigation bar
* Hero banner with promotional content
* Home loan refinancing section
* Savings account section
* Business banking section
* Fraud and scam protection cards
* Travel banking section
* Online banking section
* Personal banking information
* Responsive footer
* Hover effects and responsive layouts

The project uses Tailwind CSS utility classes instead of custom CSS. Tailwind is loaded through the CDN in the HTML file.

##  Technologies Used

* HTML5
* Tailwind CSS
* Responsive Design
* CSS Utility Classes
* External Images

##  Tailwind CSS

This project uses the Tailwind CSS CDN:

```html
<script src="https://cdn.tailwindcss.com"></script>
```

No separate CSS file is required.

##  Responsive Design

The website uses Tailwind's responsive utility classes such as:

```text
md:grid-cols-2
md:grid-cols-3
md:text-4xl
md:flex
```

This allows the layout to adapt to desktop, tablet, and mobile screen sizes.

##  Main Sections

### Hero Section

The homepage contains a promotional hero section featuring:

> Up to 130,000 bonus Qantas Points and $250 cashback

with a call-to-action button.

### Refinancing

A home loan refinancing section provides information about speaking with a home loan expert.

### Savings

The savings section encourages users to explore savings accounts.

### Business Banking

The business banking section provides information about managing, growing, and financing a business.

### Fraud & Security

The website includes three fraud and security information cards covering tax scams, fraud alerts, and online safety.

### Travel Banking

A dedicated travel section provides information for customers travelling within Australia or overseas.

### Online Banking

The online banking section covers NAB Internet Banking, the NAB app, and personal banking tools.
