# Student Management Dashboard

A simple and responsive **Student Management Dashboard** created using **HTML5** and **Tailwind CSS**.

This project is beginner-friendly and demonstrates how to create a basic dashboard layout using Tailwind CSS utility classes.

##  Project Features

* Simple navigation bar
* Welcome section
* Student statistics
* Total students count
* Present students count
* Absent students count
* Student list table
* Student course information
* Student attendance status
* Responsive design
* Simple footer

##  Technologies Used

* HTML5
* Tailwind CSS
* GitHub

##  How to Run

1. Open the project folder:

2. Open `index.html` in your browser.

No installation is required because Tailwind CSS is included using the CDN.

## Responsive Design

The project uses Tailwind CSS responsive classes.

On small screens, the cards are displayed in a single column.

On medium and larger screens, the statistics cards are displayed in three columns.

```html
grid grid-cols-1 md:grid-cols-3
```
